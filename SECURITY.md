# Security

Do not include exploit details, credentials, or sensitive user data in public issues.

If a concern involves a potential vulnerability, contact the maintainer privately via the contact options available on [their GitHub profile](https://github.com/kolapoimam). If GitHub's private vulnerability reporting is enabled for this repository, prefer that channel.

For regular bugs or feature requests, [open an issue](https://github.com/kolapoimam/muslim-icons/issues).
